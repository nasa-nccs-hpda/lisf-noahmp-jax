# jax-port: LISF (Land Information System Framework) in Python/JAX

JAX port of selected parts of LIS (land models Noah 3.9/3.6, Noah-MP 4.0.1 and 5.0 (with land ice), CLSM F2.5; HyMAP2 routing; ensembles, perturbations, EnKF soil-moisture DA), with the code, validation tools and recipes needed to run them and compare with the real Fortran LIS built with GNU 14.2. Reduced scope, not a full LIS.

* Status, results and open gaps: `STATUS_20261022.md`. Read it before citing any result.
* Where the external data, binaries and environments are, and what each run needs: `DATA_AND_PATHS.md`.
* Reproduce one Noah-MP result end to end (4.0.1 and 5.0; Fortran vs JAX, SGP, one year, with expected numbers): `REPRODUCE_NOAHMP.md` (not yet followed by anyone but the author).
* Everything at once: `gpu/run_variants.sh` submits the Fortran/JAX timing pairs, a shared-node JAX run and a summary job (`gpu_runs/<name>/SUMMARY.md`). Required variables: `DATA_AND_PATHS.md`.
* Dated record of everything done, including failures: `LOG.md`.
* Results and report: `Reports/BENCHMARKS.md`, `Reports/REPORT.md`; goal and criteria: `Reports/GOAL.md`, `Reports/ACCEPTANCE_CRITERIA.md` (DRAFT, tolerances assistant-chosen, see its 2026-10-22 amendment); environment: `Reports/ENVIRONMENT.md`; recipes and per-check folders: `Reports/CLSM_RUN_RECIPE_20261022.md`, `Reports/clsm_sensitivity_20261022/`, `Reports/gate_free_20261021/`.
* Briefings (PDF, 2026-10-24, with figures): `status_slides/` has a management, a science and a developer briefing (draft, see its README).

LIS-style front end: `python -m lisjax.lis [-C CASE_DIR] lis.config` reads `Land surface model`, the start/end keys, `Output directory` and the forcing directory of a LIS configuration and runs the matching ported model (Noah 3.9/3.6/3.3/3.2, Noah-MP 4.0.1, CLSM F2.5, Mosaic).

## Layout
- `noah39_jax.py`, `noahmp401_jax.py`, `noahmp401_glacier_jax.py`, `clsm_jax.py` – single-purpose physics cores.
- `lisjax/` – the LIS-style programs: `config.py`, `params*.py`, `forcing.py`, `model*.py`, `run.py` / `run_mp.py` / `run_clsm.py` (drivers, history, restart), `hymap2.py`, `da.py`, `pert.py`, `clsm_tables.py` (generated by `gen_clsm_tables.py`), `compare_hist.py`, `bench_conus.py`.
- `lis/` – validation against real LIS runs: dump readers, open-loop replays (`replay*.py`, `dumpio*.py`).
- `lis_patches/` – everything changed to build and instrument LISF (serial-build fixes, dump hooks, environment scripts).
- `gpu/` – SLURM job files, `run_variants.sh`, `summarize_variants.py`; `gpu_runs/` their outputs (git-excluded).
- `baseline/` – first-phase standalone Fortran driver around Noah 3.9, noise-floor tools.
- `Reports/`, `status_slides/`.

## Quick reproduction
```
source dev/lisf_deps/env_lis.sh                       # GNU 14 + libraries (Fortran side)
JAX_PLATFORMS=cpu python3 -m lisjax.run_clsm BASE OUT lis.config 2017020100 2017020106   # CLSM 6 h, CPU
python3 lisjax/compare_hist.py BASE/lisout OUT        # compare with the real LIS output
python3 lisjax/run_mp.py <case dir> <out dir> <lis.config> 20170201 20170204             # Noah-MP (ensembles, perturbation, EnKF DA if configured)
gpu/run_variants.sh                                   # everything on V100 nodes (see DATA_AND_PATHS.md)
```
This directory is its own git repository (branch main, private remote nasa-nccs-hpda/lis); the outer LISF clone shows `jax-port/` as untracked and its git state is not touched. Commits are made locally and pushed only on request (`git status` shows what is ahead of origin). Owner: G. Tamkin.
